## Running Llama3-8B Inference

This directory contains the encrypted Llama3-8B Implementation. Follow the instructions to run the Llama3-8B inference.


### 1. Build and enter the Cerium environment

Follow the root [README](../../README.md) to build the Cerium framework and envrionment 


### 2. Download the native Llama 3.1-8B checkpoint

Accept the Llama license for [meta-llama/Llama-3.1-8B](https://huggingface.co/meta-llama/Llama-3.1-8B) on Hugging Face.  Set `HF_TOKEN` to download and verify the Llama-3.1-8B Model Weights checkpoint:

```bash
HF_TOKEN=<your-token> bash download_llama.sh
```

The downloader writes `consolidated.00.pth`, `params.json`, and
`tokenizer.model` to `llama_models/model_weights/Llama3.1-8B/`.

### 3. Create  prompt inputs and packed model parameters

[llama_models/prompts.py](llama_models/prompts.py) contains the prompts used for the encrypted Llama-3.1-8B inference. Generate the packed prompts and attention masks by running:

```bash
bash generate_packed_inputs.sh
```

Then generate packed model weights for the 32 transformer blocks. Modify `MAX_JOBS` as appropriate. 

```bash
MAX_JOBS=8 bash generate_packed_weights.sh
```
### 4. Generate and compile the Cerium Llama program

To generate the program kernel sources run:

```bash
bash compile_llama_cerium.sh
```

This generates shared functions with the 1-GPU/1-block configuration,
GPU-local functions for 2, 4, and 8 GPUs, and every 1-, 2-, 4-, and 8-GPU
topology for 4, 8, 16, and 32 blocks.

Then build all of them for the desired CUDA architectures:

```bash
CUDA_ARCHITECTURES=80,90,100 bash build_llama_cuda.sh
```

`compile_llama_cerium.sh` creates the generated source under `outputs/`.
`build_llama_cuda.sh` builds and stages the generated standalone functions and
every configuration generated by that script under `outputs/compiled/`.

`CUDA_ARCHITECTURES` defaults to `80,90,100`. Provide a comma-separated list
to build for a different set of GPU architectures.

| GPU | CUDA_ARCHITECTURES |
| --- | --- | 
| A100 | 80 |
| H100 | 90 |
| B200 | 100 |


### 5. Create remappable plaintext inputs

After the Cerium programs and packed parameters exist, create the remappable plaintext weights used by the encrypted inference.

First a smoke test:
```bash
TOTAL_BLOCKS=4 BATCH_SIZE=4 MAX_JOBS=8 bash generate_remapables.sh
```

Then run generate the encoded model weights for all 32 blocks:
```bash
TOTAL_BLOCKS=32 BATCH_SIZE=4 MAX_JOBS=8 bash generate_remapables.sh
```

This produces the encoded model weights in `llama_plaintexts/`. Set `MAX_JOBS` and `BATCH_SIZE` according to system capability.

### 6. Run the Llama Inference

To run the native unpacked model and compare its block-31 output with the
encrypted result for one prompt, run:

```bash
bash run_llama_unpacked.sh --data_sample 0
```

First a smoke test, this runs the first block (block 0) on data_sample 0. The outputs are written to logs/
```bash
bash run_llama.sh --data_sample 0 --block_start 0 --num_blocks 1  --gpus 1
```

To run the full model,
```bash
bash run_llama.sh --data_sample 0 --block_start 0 --num_blocks 32 --gpus 1
```

`--block_start 0` is the full-model entry point. 

It is also possible to run the model in stages in case your system memory can't hold the full model. For example, to run the llama inference in groups of 8 blocks:

```bash
bash run_llama.sh --data_sample 0 --block_start 0 --num_blocks 8 --gpus 1
bash run_llama.sh --data_sample 0 --block_start 8 --num_blocks 8 --gpus 1
bash run_llama.sh --data_sample 0 --block_start 16 --num_blocks 8 --gpus 1
bash run_llama.sh --data_sample 0 --block_start 24 --num_blocks 8 --gpus 1
```


### 7. Get the predicted token

```bash
bash get_token.sh --data_sample 0
```

### Generated directories

- `llama_models/model_weights/Llama3.1-8B/`: downloaded model checkpoint.
- `llama_models/params/`: packed transformer parameters.
- `llama_models/llama_inputs/`: packed prompt and attention-mask inputs.
- `outputs/`: Cerium-generated CUDA source and build products.
- `outputs/compiled/`: compiled Cerium libraries and metadata.
- `llama_plaintexts/`: remappable plaintext weights.
- `llama_ciphertexts/`: encrypted inputs.
- `fhe_outputs/`: encrypted-inference intermediate outputs.
